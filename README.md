# Operaciones DDH – v1.14 PRUEBA

Versión completa de prueba.

## Proyección equipos
- Permite cargar una o varias capturas de la tabla de pozos.
- OCR ejecutado localmente en el navegador mediante Tesseract.js.
- Intenta completar Equipo/Sonda, Pozo, PEND. [m] y Fecha término.
- Hasta 10 filas.
- Los datos quedan editables para revisión manual.
- Los cuadros “Equipos para coordinación” y “Equipos que necesitan actualización en Cronos” siguen siendo manuales y no se modifican al leer capturas.
- PDF corporativo ordenado de menor a mayor por metros por perforar, con escala rojo → amarillo → verde.

> Nota: el OCR depende de la nitidez y estructura de la captura; siempre revisar antes de generar el PDF/correo.
